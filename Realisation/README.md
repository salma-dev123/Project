# Mini Convertisseur & Calculatrice CLI

Ce projet est une **application CLI en PHP** qui permet :
- La conversion d'un entier en **binaire** et **hexadécimal**.
- L'exécution d'**opérations logiques** entre deux entiers (ET, OU, XOR, NON, décalages).
- Le traitement d'un **lot de valeurs** (mode batch via fichier JSON).
- La gestion d'erreurs et validation des entrées.
